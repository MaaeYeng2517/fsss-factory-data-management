# หน้าแรก (Homepage) — FSSS Raw Material Management System

ไฟล์: `src/app/page.tsx`

## โครงสร้างหน้า (ส่วนๆ ตาม README.md)

1. Header — ชื่อระบบและคำอธิบาย
2. Nav (anchor links) — ลิงก์ไปยังแต่ละส่วน (#tech, #features, #schema, #setup, #screens, #design, #more)
3. Quick Links — การ์ดลิงก์ไปยังหน้าฟีเจอร์ (/raw-materials, /raw-materials/materials, /raw-materials/purchase-orders, /raw-materials/goods-receipts, /raw-materials/material-issues, /raw-materials/stock-count, /dashboard, /employees)
4. Sections — แต่ละส่วนแสดง title + description พร้อมลิงก์ไปยังหน้าที่เกี่ยวข้อง

## ส่วนที่ครอบคลุม (จาก README.md)

- เทคโนโลยีที่ใช้
- ฟีเจอร์หลัก (7 ข้อ)
- โครงสร้างฐานข้อมูล
- การเริ่มใช้งาน
- หน้าจอหลัก
- การออกแบบที่สำคัญ
- การพัฒนาเพิ่มเติม
